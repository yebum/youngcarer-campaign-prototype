# 돌봄을 돌봄 — 영케어러 캠페인 웹 디자인 시안 (v4)

영케어러(가족돌봄청년) 캠페인 랜딩 페이지의 **디자인 시안(프로토타입)** 입니다.
실제 후원 페이지가 아니며, 결제·메시지 저장 기능은 연결되어 있지 않습니다.

- 정적 사이트: `index.html`, `style.css`, `responsive.css`, `app.js`, `img/`
- 빌드 도구 없이 그대로 열거나 GitHub Pages로 배포합니다
- 인터랙션: 스크롤 등장, 패럴랙스, 멈춘 시계와 다시 도는 시계, 통계 카운트업, 응원 메시지 추가(화면에서만), 후원 금액 선택
- 검색엔진에 노출되지 않도록 `noindex` 를 넣어 두었습니다

사진과 문구는 캠페인 시안 자료에서 가져온 것으로, 저작권은 각 권리자에게 있습니다.
